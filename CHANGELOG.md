# Changelog

## Unreleased

### Added

- Added Scheduled activation mode with configurable weekdays and start/end times directly in the menu bar popover.
- Added automatic schedule evaluation when Vesila launches or the Mac resumes, wakes, or its clock changes.

### Changed

- Manual on/off changes during an active scheduled window now apply only to that window; the next scheduled window starts fresh.
- Schedule configuration is persisted and restored across launches.
- Schedule editing now stays inside Vesila's menu bar UI instead of opening a separate window.
- Replaced the schedule time fields with compact segmented time controls designed for the menu bar popover.
